# 기본 데이터와 심화 데이터의 차이

두 데이터는 내용과 건수가 달라서 점수를 모델 선택에 섞어 쓰지 않습니다. 이 문서는 난이도 차이가 결과에 어떻게 나타났는지 설명하려고 나란히 놓은 것입니다.

그래프: [basic_vs_advanced.png](basic_vs_advanced.png)

## 1. 데이터 특성 (문서 주제, train 기준 토큰 수는 klue/roberta-base 토크나이저)

| 항목 | 기본 | 심화 |
|---|---:|---:|
| train / validation / test | 360 / 120 / 120 | 180 / 60 / 60 |
| 입력 길이 중앙값 (토큰) | 51 | 477 |
| 입력 길이 상위 10% 지점 (토큰) | 58 | 784 |
| 가장 긴 입력 (토큰) | 67 | 894 |
| 190토큰을 넘는 train 사례 | 0건 | 124건 |
| 한 묶음(group) 안의 라벨 종류 | 1가지 (같은 라벨) | 3가지 (서로 다른 라벨) |

## 2. 같은 모델의 validation Macro F1

'같은 설정'은 192토큰, 학습률 2e-5, 에포크 3입니다. 심화의 '512토큰·에포크 6'은 그 모델로 가장 좋았던 학습률의 결과입니다(시드 1개).

| 모델 | 기본 (같은 설정) | 심화 (같은 설정) | 차이 | 심화 (512토큰·에포크 6) |
|---|---:|---:|---:|---:|
| TF-IDF + 로지스틱 회귀 | 0.9500 | 0.8157 | -0.1342 | 해당 없음 |
| TF-IDF + LinearSVC | 0.9500 | 0.8155 | -0.1344 | 해당 없음 |
| TF-IDF + MultinomialNB | 0.9327 | 0.8154 | -0.1173 | 해당 없음 |
| klue/roberta-base | 0.9917 | 0.6835 | -0.3081 | 0.8471 |
| klue/bert-base | 0.9833 | 0.6060 | -0.3774 | 0.8010 |
| KoELECTRA-small | 0.8998 | 0.1667 | -0.7332 | 0.4575 |

## 3. test 최종 평가

| 데이터 | 건수 | 선택 모델 | 선택 모델 정확도 / Macro F1 | 기준 모델(TF-IDF+LR) 정확도 / Macro F1 |
|---|---:|---|---|---|
| 기본 | 120 | klue/roberta-base (`roberta_lr2e5`) | 0.9917 / 0.9917 | 0.9667 / 0.9666 |
| 심화 | 60 | klue/roberta-base (`roberta_len512_ep6_lr5e5`) | 0.8167 / 0.8148 | 0.8000 / 0.7999 |

## 읽는 법

- **기본은 모든 모델에 쉽습니다.** 0.90~0.99이고 사전학습 모델이 가장 높습니다.
- **심화에서 같은 설정을 쓰면 순위가 뒤집힙니다.** TF-IDF 계열은 0.13쯤 떨어지는 데 그치지만 사전학습 모델은 0.17~0.68로 무너집니다. 입력을 192토큰에서 자르는데 심화는 긴 글이 많고, 라벨을 정하는 구간('이번에 전달하는 본문')이 잘린 뒤에 나오는 사례가 많기 때문입니다. TF-IDF는 글 전체를 봅니다.
- **입력 길이와 에포크를 늘리면 일부만 회복됩니다.** klue/roberta-base가 0.68에서 0.85로 올라 기준 모델을 조금 넘지만 기본의 0.99에는 한참 못 미칩니다. 남은 차이가 심화 데이터 자체의 어려움입니다: 참고 기록이 섞여 있고, 같은 소재가 세 라벨에 모두 나오며, 학습 데이터가 절반입니다.
- **test에서도 같습니다.** 선택 모델의 Macro F1이 기본 0.99, 심화 0.81입니다.
