# long_comment01: 긴 댓글에서 혐오 표현을 잡는지 확인

서비스는 댓글을 4,000자까지 받습니다(`MAX_INPUT_CHARS`, 처음 코드의 값). 하지만 분류 모델은 앞 128토큰(약 280자)만 읽습니다. 학습·평가에 쓴 댓글은 가장 길어도 137자(69토큰)여서, 지금까지의 평가에는 긴 글이 한 번도 없었습니다. 그래서 긴 글을 만들어 넣어 봤습니다(2026-10-15).

- 결과 표: [summary.md](summary.md), 그래프: [long_comment.png](long_comment.png)
- 입력마다의 결과: [classify_results.csv](classify_results.csv), 실제 서버 요청: [requests.jsonl](requests.jsonl)

> **내용 주의:** 결과 파일에는 실제 댓글의 혐오 표현이 들어 있습니다.

## 조건

- **혐오 댓글:** validation hate 199건 가운데, 분류 모델이 단독으로 hate라고 맞힌 136건 전부입니다. test는 최종 평가용이라 쓰지 않았습니다.
- **평범한 글:** validation none 댓글 가운데 분류 모델이 단독으로 none(확신도 0.93 이상)이라고 본 205건을 시드 42로 섞어 이어 붙였습니다.
- **비교:** ① 평범한 글만 ② 혐오 댓글만 ③ 혐오 댓글을 맨 앞에 두고 평범한 글 1,000자 ④ 평범한 글 100/200/300/500/1,000/3,000자 뒤에 혐오 댓글
- **권장 조치:** 서비스 화면의 규칙과 같습니다. none이면서 확신도가 0.93 이상이면 그대로 게시, 0.93 미만이면 사람 검토, offensive나 hate면 고쳐 쓰는 경로입니다.
- **실제 서버:** ④의 300자와 1,000자에서 혐오 댓글을 id 순서로 5건씩 step10 서버(gemma4:e4b)에 보내고, 화면의 대량 검수와 같은 함수로 권장 조치를 정했습니다. 처음 계획은 1,000자 5건이었습니다. 1,000자 글은 생성 모델의 출력 한도를 넘길 수 있어 300자 5건을 더했습니다.
- **정한 값:** 길이 단계(100~3,000자)는 비교로 고른 값이 아니라 정한 값입니다. 0.93은 서비스의 확신도 규칙 기준값입니다.

## 결과

| 혐오 댓글 136건을 | 악플로 판정 | 사람 검토 | 그대로 게시 |
|---|---:|---:|---:|
| 혼자 넣으면 | 100% | 0% | 0% |
| 앞에 평범한 글 100자 | 5% | 46% | 49% |
| 앞에 200자 | 0% | 13% | 87% |
| 앞에 300자 이상 | 0% | 0% | 100% |
| 맨 앞에 두고 뒤에 1,000자 | 7% | 33% | 60% |

- 평범한 글만 넣으면 98~100%가 그대로 게시입니다(대조군).
- **실제 서버:** 300자 5건은 모두 혐오 댓글이 든 원문이 '그대로 게시'였습니다(분류 none, 확신도 0.96~0.97). 1,000자 5건은 모두 '처리 실패'였습니다. none 지침은 원문을 그대로 돌려주게 하는데, 긴 원문을 돌려주다 생성 모델이 출력 한도(512토큰)를 넘겨 답이 잘렸습니다(`incomplete`).

## 해석

- **잘림만의 문제가 아닙니다.** 앞에 100자를 붙였을 때는 136건 중 135건에서 혐오 댓글이 앞 128토큰 안에 다 들어 있었습니다. 그런데도 5%만 악플로 판정했습니다. 분류 모델이 글 전체의 분위기로 판단해서, 일부만 혐오인 글을 none으로 봅니다. 학습 데이터가 짧은 댓글 하나씩이라 이런 글을 본 적이 없습니다.
- **300자를 넘으면 아예 읽지 못합니다.** 혐오 댓글이 앞 128토큰 밖으로 밀려 잘리므로, 544건 모두 none(확신도 0.95 이상)이 됩니다. 확신도 규칙(0.93 미만이면 사람 검토)도 잡지 못합니다.
- **긴 정상 댓글도 처리하지 못합니다.** 1,000자 글은 none으로 판정돼도 생성 단계에서 실패합니다.

## 한계

- 긴 글은 서로 다른 짧은 댓글을 이어 붙여 만든 것이라, 한 사람이 쓴 진짜 긴 댓글과 다를 수 있습니다.
- 실제 서비스에 긴 댓글이 얼마나 들어오는지는 모릅니다(실제 요청 기록이 없습니다).
- 분류 모델이 혼자서도 hate로 맞히지 못한 혐오 댓글(199건 중 63건)은 빼고 시험했습니다.
- 실제 서버로는 10건만 보냈습니다.
