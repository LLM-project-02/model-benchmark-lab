최종 입력(`generation_eval.jsonl`, test에서 뽑은 24건)을 두 모델에 2번씩 보낸 결과입니다. 두 모델은 같은 분류 결과와 같은 프롬프트를 받았습니다.

- 모델별 수치: [final_summary.csv](final_summary.csv)

## 품질

- **차이(로컬 - 상용):** -0.31점 (95% 구간 -0.92~+0.10). 구간이 0을 포함해 이 자료로는 두 모델이 구분되지 않습니다.
- **입력별:** 24건 가운데 점수가 같은 입력 18건, 상용이 높은 입력 5건, 로컬이 높은 입력 1건입니다.
- **채점:** llm:claude-opus-5-5 (대화 세션에서 채점), 가린 채점표(blind_sheet.md). 어느 모델의 답변인지 가렸고, 정답 라벨의 정책을 기준으로 했습니다.

| 정답 라벨 | 로컬 | 상용 | 차이 |
|---|---:|---:|---:|
| none | 8.00 | 8.00 | +0.00 |
| offensive | 5.94 | 5.81 | +0.12 |
| hate | 4.75 | 5.81 | -1.06 |
| 분류기가 정답을 맞힌 17건만 | 6.91 | 7.38 | -0.47 |

| 항목 (각 2점 만점) | 로컬 | 상용 |
|---|---:|---:|
| 정책 준수 | 1.33 | 1.38 |
| 필수 내용 | 1.48 | 1.54 |
| 근거 없는 주장 없음 | 1.42 | 1.62 |
| 명확성 | 2.00 | 2.00 |

## 분류 모델로 다시 판정한 결과 (참고)

고친 문장을 앞단의 분류 모델에 다시 넣은 결과입니다. 분류 모델은 뜻이 바뀐 것은 보지 못합니다.

| 확인 | 로컬 | 상용 |
|---|---:|---:|
| offensive 댓글을 고친 뒤 none | 94% | 81% |
| hate 댓글을 고친 뒤 none | 75% | 75% |
| hate 댓글에 게시 불가 안내 | 25% | 38% |
| none 댓글을 원문 그대로 | 100% | 100% |

## 비교 조건

- **같게 둔 것:** 입력 24건, 분류 결과, 프롬프트(step08), temperature 0.2, 최대 출력 512토큰, 반복 2회.
- **생각 단계:** 로컬은 `think: false`, 상용은 reasoning effort `none`. 둘 다 생각 단계 없이 바로 답합니다.
- **다른 것:** 로컬에만 JSON 형식 강제(`format`: json_schema(AnswerPayload))가 있습니다. 상용은 프롬프트로만 형식을 요구합니다. 토크나이저가 달라 같은 프롬프트도 토큰 수가 다릅니다.

## 한계

- 입력이 24건(라벨당 8건)이라 작은 차이는 우연일 수 있습니다. 95% 구간을 함께 봅니다.
- 채점은 사람이 `llm_spotcheck.csv`를 확인하기 전까지 참고값입니다.
- 7건은 분류기가 정답과 다른 라벨을 골라 다른 정책이 적용됐습니다. 두 모델이 같은 조건이지만 그 입력의 점수는 생성 모델의 실력만 보여 주지 않습니다.
- 응답 시간은 이 노트북과 이날의 네트워크에서 잰 값입니다.
