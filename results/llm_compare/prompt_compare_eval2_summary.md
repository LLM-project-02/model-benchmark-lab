# 지시문 v1 vs v2 비교 (eval2)

- 지시문 지문: v1 `f0f567a2668882da...`, v2 `fae1ddec38b313c4...`
- A 분류기 판정 정답: 18/30. 로컬 답은 후처리 적용, 지시 위반은 후처리 전 기준
- '확인 불가에서 원문과 다르다'는 글자로만 세어 부정확하고 v2에서 일부 허용되므로 채택 규칙에 쓰지 않는다

- R1 로컬 수정안 5건 이상 증가: 만족
- R2 상용 재검토·수정안 유지: 만족
- R3 대조 오경보 유지: 불만족
